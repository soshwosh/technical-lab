# Technical Lab
A space for deep-diving and test-driving random technical topics in 1-hour sessions with a senior developer / technical mentor.

## Sessions
To keep everything nicely scoped so the labs stay productive, the sessions will fall into one of the two following types:
- **Discussion:** For high-level or complex topics that may be too big for a 1-hour code sandbox without lots of prep work. For understanding underlying design, protocols, or theory. Building technical communication and presentation skills.
- **Live Code:** For specific and atomic topics that are best understood by writing code, or for testing out a framework or pattern you haven’t had the chance to during your day-to-day work tasks. Building practical technical skills.

We'll probably do a little of both in each lab, but thinking about it this way will keep us from biting off more than we can chew. 

## Artifacts & Organization
The artifacts for each session can be found within the "Sessions" folder. Each session will get it's own folder named by the date and topic of the session. There'll be a README for each session to jot down key ideas, questions, resources, and to link to other artifacts. 

Other artifacts may include diagrams, in the case of the Discussion sessions, and code, in the case of the Live Code sessions.
